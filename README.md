# LAST SURVIVOR MAX

An original browser-based 3D battle-royale prototype built with Babylon.js.

## Run locally
Open `index.html` in a modern browser with an internet connection. Babylon.js is loaded from its official CDN.

## Controls
- WASD: move
- Mouse: look / aim (click Deploy to lock pointer)
- Left mouse: fire
- R: reload
- Shift: sprint
- Space: jump
- Esc: release pointer / pause

## Current prototype features
- 3D island scene with buildings, roads, trees, rocks, lighting, shadows and atmospheric fog
- Third-person character and rifle geometry
- Enemy bots with basic movement and firing behaviour
- Health, ammo, reload, eliminations, minimap and shrinking safe zone

## Important scope note
This is an early playable prototype, not a complete commercial battle-royale game and not a Free Fire asset clone. It currently uses procedural placeholder models and simple bot logic. It does not yet include real online multiplayer, advanced motion-captured animations, inventory/loot, vehicles, matchmaking, or production server infrastructure. Those need separate assets, systems and testing.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save. GitHub will publish the site at:
